Как подключить Zara к Meta
3 КЛЮЧА + ПОСТОЯННЫЙ ТОКЕН — ВСЁ ЧТО НУЖНО
1
META ACCESS TOKEN
⚠ ВРЕМЕННЫЙ 1-2ч
Это ключ доступа к твоим данным Facebook. Через него Zara читает кампании, пиксель и аудитории.
1
Перейди на developers.facebook.com/tools/explorer
2
Выбери своё приложение (или создай новое — кнопка My Apps → Create App)
3
В разделе Permissions добавь: ads_read ads_management business_management
4
Нажми Generate Access Token → скопируй строку вида EAABwzLixnjYBO...
2
AD ACCOUNT ID
✅ ПОСТОЯННЫЙ
ID твоего рекламного аккаунта. Не меняется. Zara использует его чтобы видеть твои кампании и расходы.
СПОСОБ 1 — через URL браузера
Открой business.facebook.com/adsmanager → посмотри адресную строку → найди ?act=123456789 → эти цифры и есть твой ID
СПОСОБ 2 — через Business Manager
Business Manager → Настройки бизнеса → Рекламные аккаунты → рядом с названием написан ID
📌 Вставляй с префиксом: act_123456789 (не просто цифры)
3
PIXEL ID
✅ ПОСТОЯННЫЙ
15-значный ID пикселя. Через него Zara видит всю воронку событий — PageView, AddToCart, Purchase — и строит аудитории.
1
Перейди на business.facebook.com/events_manager
2
В левой панели Data Sources → выбери свой пиксель
3
Вкладка Settings → скопируй 15-значный Pixel ID
♾️
ПОСТОЯННЫЙ ТОКЕН — System User Token
НЕ ИСТЕКАЕТ · РАБОТАЕТ 24/7 · РЕКОМЕНДУЕТСЯ
⭐ ЛУЧШИЙ ВАРИАНТ
Обычный токен из Graph Explorer живёт 1-2 часа — неудобно. System User Token создаётся один раз через Business Manager и работает бессрочно. Именно его нужно вставить в Zara.
1
Открой Business Manager
Перейди на business.facebook.com → Настройки бизнеса (шестерёнка в левом нижнем углу)
2
Создай System User
В левом меню найди Пользователи → Системные пользователи → кнопка Добавить → назови, например, nexus-zara → роль Администратор
3
Дай доступ к активам
В карточке System User → Добавить активы → выбери свой Рекламный аккаунт и Пиксель → разрешения: Manage campaigns, View performance
4
Сгенерируй токен
В карточке System User → кнопка Generate New Token → выбери своё приложение → добавь permissions: ads_read ads_management business_management → Generate Token
5
Скопируй и вставь в Zara
Токен покажется один раз — сразу скопируй и вставь в поле ACCESS TOKEN выше. Сохрани копию в надёжном месте. Этот токен не истекает никогда.
⚡ ИТОГ: business.facebook.com → Настройки бизнеса → Системные пользователи → Добавить → дать доступ к аккаунту и пикселю → Generate Token → скопировать → вставить в Zara

LTV Lookalike — Точная аудитория
Базируется на покупателях с высоким LTV (lifetime value). Facebook строит портрет по тем кто купил 2+ раз. Это 1% самых похожих из всей базы — аудитория которая ещё не видела твой оффер.
База: Покупатели 90д ~2,400 чел
LAL 1% размер ~42,000
Статус выгорания ✅ СВЕЖАЯ
Frequency cap 1.4 (норма)
💡 Запускай Value Optimization с pixel event Purchase + value parameter для максимального LTV signal

Структура кампании без пересечений

AD SET 2 — LAL 3% (исключить 1%)
Исключить: LAL 1%, все покупатели 180д
AD SET 3 — Retarget AddToCart

⛔ УБРАТЬ — Broad без пикселя
Убыточно. Без сигнала пикселя — CPA x3-5

Оффер с ROI 40%+ — критерии
✔ CR ≥ 3% — конверсия лендинга. Ниже — проблема оффера или крео
✔ EPC ≥ $1.50 — доход за клик. Ниже — оффер не окупает трафик
✔ Апрув ≥ 60% — реальные подтверждённые продажи
✔ Нет cap — оффер принимает неограниченный объём трафика
✔ Pixel-friendly — лендинг позволяет ставить пиксель + CAPI
📲
Куда добавлять данные в Facebook
1. Events Manager → Pixel
Настрой передачу Purchase с параметрами: value, currency, email (hashed), phone (hashed), fbc, fbp
2. CAPI → Conversions API
Keitaro → Постбэки → Facebook CAPI. Дублирует пиксельные события с сервера. EMQ +2-3 балла
3. Custom Audiences → Загрузить список
Audiences → Create → Customer list. CSV с email/phone покупателей. База для LAL строится здесь
4. Value-based Lookalike
Audiences → Create → Lookalike → Value-based source. Выбери Custom Audience покупателей с value

Убыточные сегменты — убрать немедленно
Broad без пикселя
CPA в 3-5 раз выше. Facebook не знает кого искать. Деньги в мусор.
LAL на холодную базу
LAL от подписчиков или кликов — не покупателей. Качество аудитории падает в 5-10 раз.
Пересекающиеся адсеты
LAL 1% и LAL 3% без исключений конкурируют между собой. CPM растёт, ROI падает.
Frequency > 3.5
Выгоревшая аудитория. CTR падает, CPM растёт. Нужна новая аудитория или пауза 7-14 дней.
AdSet в обучении >7д
Если Learning не завершается за 7 дней — слишком мало конверсий. Увеличь бюджет или смени цель.
Без исключения покупателей
Реклама попадает тем кто уже купил. Деньги тратятся впустую. Всегда исключай покупателей 180д.
