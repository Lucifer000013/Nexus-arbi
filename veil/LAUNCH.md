# Veil — путь к запуску

Сейчас: клиентский прототип без демо-данных (пустой интерфейс). Всё хранится в `localStorage`.
Вся связь с сервером изолирована в `js/transport.js`.

## Что нужно до публичного запуска
1. **Аккаунты**: регистрация по номеру/e-mail, уникальный username, поиск пользователей.
2. **Сервер сообщений**: WebSocket, доставка, офлайн-очередь, push-уведомления.
3. **Шифрование**: E2E для секретных чатов (Signal protocol / libsodium), ключи только на устройствах;
   серверное удаление чата у обоих (`deleteChatForAll`) и таймеры исчезновения на стороне сервера.
4. **Медиа**: хранилище (S3-совместимое), шифрование файлов, лимиты, антивирус/модерация.
5. **Карта**: геопозиция только выбранным контактам, TTL позиции, режим призрака на сервере; Leaflet → MapLibre + свой провайдер тайлов (сейчас CARTO/OSM — проверить лицензии/лимиты).
6. **Группы**: роли, инвайт-ссылки, публичный каталог, модерация.
7. **Платные группы и Premium**: платёжный провайдер (Stripe / App Store / Google Play), чеки, отмена подписки.
8. **Юридическое**: политика конфиденциальности, ToS, возрастные ограничения, требования сторов (UGC-модерация, жалобы, блокировки).
9. **Упаковка**: PWA (manifest + service worker) → Capacitor/Swift/Kotlin для App Store и Google Play.
