# Veil — подготовка к App Store

## Сборка iOS (нужен Mac с Xcode и аккаунт Apple Developer, $99/год)
```
cd veil
npm install
npm run ios:add     # один раз: создаёт папку ios/
npm run ios:sync    # собирает www/ и синхронизирует с Xcode-проектом
npm run ios:open    # открывает Xcode → Signing & Capabilities → Archive → Distribute
```
Bundle ID задан в `capacitor.config.json` (`app.veil.messenger`), при необходимости замените на свой.
Иконка: `assets/icon-1024.png` (без прозрачности) → Xcode Assets → AppIcon.

## Уже сделано в приложении
- Жалоба на пользователя и блокировка (обязательно для приложений с UGC, гайдлайн 1.2).
- Удаление аккаунта внутри приложения (гайдлайн 5.1.1(v)).
- Экран «Конфиденциальность и условия» (ссылки задайте в `window.VEIL_LEGAL = { privacy, terms }`).
- Leaflet кладётся локально при сборке, приложение не зависит от CDN.

## Что осталось до отправки
1. **Бэкенд** — реализовать `js/transport.js` (аккаунты, сообщения, группы, жалобы, удаление аккаунта). Без работающего сервера Apple отклонит приложение (гайдлайн 2.1: нужен рабочий функционал и демо-аккаунт для ревью).
2. **Sign in with Apple** — обязателен, если добавите вход через Google/Facebook и т.п. При входе только по номеру/e-mail не требуется.
3. **Оплата** — Premium и платные группы (цифровой контент) должны идти через **In-App Purchase** (StoreKit, гайдлайн 3.1.1), а не через сторонний платёжный сервис. Плагин: RevenueCat или `@capgo/native-purchases`. Комиссия Apple 15–30%. «Автор получает 90%» в тексте нужно пересмотреть.
4. **Геолокация** — в `Info.plist` добавить `NSLocationWhenInUseUsageDescription` («Показываем вас на карте только выбранным контактам»); для фото/видео `NSPhotoLibraryUsageDescription`, `NSCameraUsageDescription`. Плагин `@capacitor/geolocation`.
5. **Шифрование** — секретные чаты сейчас без реального E2E. Не заявляйте «сквозное шифрование» в описании, пока оно не реализовано (Signal protocol / libsodium). При использовании шифрования в анкете экспорта указать ответ на вопрос об encryption (`ITSAppUsesNonExemptEncryption`).
6. **Модерация** — процесс реакции на жалобы в течение 24 ч, фильтр запрещённого контента, контакт поддержки в приложении и в карточке App Store.
7. **Push** — `@capacitor/push-notifications` + APNs-ключ.
8. **App Store Connect**: название, подзаголовок, описание, скриншоты (6.9" и 6.5"), URL политики конфиденциальности, URL поддержки, возрастной рейтинг (чат с UGC — обычно 17+), анкета App Privacy (данные: контакты, геолокация, сообщения, идентификаторы).
9. **Тест** — TestFlight перед отправкой на ревью.

## Позиционирование
Veil — мессенджер, а не соцсеть: нет ленты и публичных профилей. Карта показывает только контакты, которых вы выбрали. Держите это в описании и в App Privacy.
